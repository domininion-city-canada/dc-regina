# CLAUDE.md

## Skills library

The `agentic-skills` plugin (github.com/phoenixtype/agentic-skills) is installed user-wide and encodes SyntaxReady's conventions. Start from `using-agentic-skills` to pick what applies; for this repo that's primarily: `marketing-site-playbook`, `design-tokens-and-ui`, `security-baseline`.

When a lesson, correction, or incident emerges here, update the matching SKILL.md and ADVISORY.md in `~/VisualStudioCodeProjects/agentic-skills`, push (bumping the plugin version), then run `claude plugin update agentic-skills@agentic-skills-marketplace` (see `self-improving-skills`).
